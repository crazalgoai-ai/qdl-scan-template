## 原型说明

- 模板分 6 套：陆基 / 千发 各有「消费者（含订单客商）」「消费者（不含订单客商）」「稽核」
- 模块级：开关 + 拖动排序（首图固定顶部）
- 字段级：开关；养殖过程支持拖动调整环节顺序
- 基地概况：基地展示、取水展示两组，字段级开关
- 养殖过程·鱼苗孵化：背景图支持上传后框选主体、孵化地点支持填文案（随该环节开关生效）
- 正式上市：感官指标、理化指标、客服电话支持自定义文本
- 认证报告：执行标准、地理标志、有机证书、浙农码、检验报告支持上传更换；检测报告取自捕捞上传
