## 原型说明

- 模板分 4 套：陆基·消费者、陆基·稽核、千发·消费者、千发·稽核
- 模块级：开关 + 拖动排序（首图固定顶部）
- 字段级：开关；养殖过程支持拖动调整环节顺序
- 正式上市：感官指标、理化指标、客服电话支持自定义文本
- 认证报告：执行标准、地理标志、有机证书、浙农码、检验报告支持上传更换；检测报告取自捕捞上传
